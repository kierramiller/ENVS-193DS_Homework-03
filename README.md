# ENVS-193DS_Homework-03
Resporitory for Environmental Science Statistics Class Homework 3

## General Information

This repository contains Homework 3 for ENVS 193DS (Environmental Data Science). The purpose of this assignment is to explore relationships between variables using statistical tests, create and update data visualizations, and develop an affective visualization based on personal data.
## Data and File Information

The repository is organized into the following folders:

- `code/`: Contains the Quarto (.qmd) file used to complete the assignment, including all code, analysis, and written responses.
- `data/`: Contains datasets used in the assignment, including the kelp dataset and personal data collected for analysis.

Additional files:
- `.Rproj`: R project file for organizing the workspace.
- `.gitignore`: Specifies files that should not be tracked by Git.
